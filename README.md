# Employee Data Analysis
Python | Pandas | NumPy

## Overview
Analyzed 40 employee records to extract business insights on salary, performance, and department trends.

## Dataset
- 40 employees | 11 columns
- Fields: Department, City, Age, Salary, Performance Score

## Analysis
- Salary statistics — Mean, Max, Min
- Department & City wise breakdown
- Top 10 performers & highest earners
- Performance category distribution
- Age group wise salary trends
- Pivot table — Department x City

## Tech Stack
Python 3.12 · Pandas · NumPy · VS Code

##  Core Business Problems Solved
This project addresses key HR and operational questions using data-driven insights:

* **Workforce Cost Optimization:** Calculated maximum, minimum, and average salary distributions across departments to identify high-cost operational business units.
* **Talent Management & Performance Mapping:** Segmented the top 10 highest-performing individuals and extracted isolated datasets of "Excellent" performers to support corporate appraisal decisions.
* **Geographic Analytics:** Built cross-tabulated matrix views (Department x City) to evaluate organizational footprint and staffing distribution across different office locations.
* **Demographic Salary Trends:** Grouped employee age brackets against compensation metrics to reveal how experience correlates with company salary bands.
